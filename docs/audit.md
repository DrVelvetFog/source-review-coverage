# The Agent Audit

A report whose coverage section is generated by running the verifier over a
repository's merge history, and whose every other finding names its evidence tier. The
same template is the one-week engagement and the self-serve kit.

```bash
bash audit/run.sh <clone> --branch main --limit 400
```

produces `audit/out/report.md` from [`audit/TEMPLATE.md`](../audit/TEMPLATE.md) with
sections 1 and 2 filled in: how many sampled merges shipped exactly the automatic merge of
what was reviewed, how many carried a residual, and the inventory of those residuals. Add
`--fetch-prs` to fetch `refs/pull/*/head` first, which the squash scan needs; without it
nothing touches the network. Sections 3 to 5 are the auditor's, each line with its tier.

## The worked example

The public history of `maziyarpanahi/openmed`, the merge-heavy repository the
specification's Appendix A sampled, at the clone used there (2026-07-28):

```
bash audit/run.sh ~/openmed-scan --limit 400
```

reports 400 merge commits sampled, 336 identity or replay, 64 residual, 0 with a clean
replay: every residual is a conflict resolution, and none is content a merge commit
carried that was in no parent. The same numbers as Appendix A, in about half a minute;
the generated report is [`audit/samples/openmed-2026-07-28.md`](../audit/samples/openmed-2026-07-28.md).

## What it is not

Not a compliance certificate, not a code review, and not a judgement about the residuals
it lists: a residual is unreviewed content, which is a fact about process, not a defect.
Section 6 of the template says so in the report itself.

A pass establishes review coverage and nothing else: not correctness, not that a human
read anything, not truthful authorship, not reviewer independence, not existence at a
time, not compliance.
